# IPTV for Android

集 **直播源全网采集、智能检测、多格式导出** 与 **全功能播放器** 于一体的 Android 应用。

## v2.0.4 更新（播放控制栏自动隐藏 + 屏幕解锁修复）

- **控制栏自动隐藏**：播放开始后上下按钮栏 3.5 秒无操作自动淡出，画面无遮挡；轻触屏幕即可唤回，暂停时保持显示方便操作，拖动进度条时不隐藏。
- **屏幕解锁修复**：修复「点击锁定后无法解锁」问题。锁定后右侧常驻悬浮解锁按钮，点击即解锁；也支持双击画面解锁、锁定时按返回键先解锁（不再误退出播放）。锁定时单击画面会提示解锁方式。

## v2.0.3 更新（线路切换提速 + 细节优化）

- **线路切换提速**：错误分级处理——HTTP 错误、格式错误、无效地址、连接超时等确定性失败立即切换到下一条线路，不再等待重试；仅网络抖动类失败快速重试 1 次（冷静期 450ms，原 1200ms）。连接超时从 15 秒缩短到 8 秒，HTTP 底层超时同步收紧。多线路频道切换响应显著加快。
- **细节优化**：全部线路失败提示自动消失不再长期遮挡画面；修复外部 m3u/m3u8 scheme 链接还原为 http(s) 地址的问题；统一检测并发设置范围（4-32）；清理若干编译警告。

## v2.0.2 更新（频道名乱码修复）

- **根治乱码**：订阅源头部样本过去用 Latin-1 解码、样本足够大时又被当作正文解析，导致 UTF-8 中文频道名变成「GOé å」「ç½ ç»„」这类乱码。现统一改为按原始字节收集后一次性智能解码（UTF-8 优先、GBK 回退、BOM 识别），多字节字符跨块截断问题一并解决。
- **历史数据自动修复**：读取频道缓存时对残留乱码字段做高置信度还原，升级后无需重新导入即可看到正确中文；解析入口与粘贴导入同样兜底，正常西欧文字（Café 等）不会被误伤。

## v2.0.1 更新（稳定性修复 + 线路切换优化）

- **修复采集/检测闪退**：响应体安全读取（限制大小）杜绝异常源超大响应导致 OOM；有界并发协程 + 挂起式信号量替代无上限协程与阻塞式 acquire，消除线程耗尽与数据竞争；进度回调、JSON 解析、存储写入全链路异常隔离；Fragment 视图销毁后异步回调安全守卫，避免已销毁 View 崩溃。
- **线路切换更稳**：播放失败不再立即换线，改为先重试当前线路 2 次（带冷静期）确认确实无效才切换；连接超时延长到 15 秒；线路真正播放成功即重置失败计数，避免网络抖动导致频繁跳线。
- **补齐外部链接唤起**：点击 m3u/m3u8/http(s) 直播源链接可直接唤起应用并自动导入。

## v2.0.0 更新（同频道多线路合并）

同一数据来源下的重复频道现在会自动合并为一个频道，像主流直播软件一样以「线路」形式呈现：

- **自动合并同名频道**：同一来源（同一订阅实例）下名称相同或规范写法一致（如 CCTV1 / CCTV-1 / 央视一套）的频道合并为一个频道组，组内每条地址作为一条线路，在列表中以「N线路」徽章显示
- **失败自动换线路**：播放某频道时，当前线路播放失败或无响应，会自动切换到下一条线路，直到找到可播放的线路；每条线路本频道内只尝试一次，避免死循环，全部失败时明确提示
- **手动选线路**：播放器顶部「线路 i/n」徽章或更多菜单的「选择线路」可弹出该频道全部线路，标注每条线路的检测状态/延迟/分组，点击即用该线路播放
- **最佳线路优先**：组内线路按「可用 → 延迟低 → 未检测 → 失效」排序，默认从体验最好的线路开始播放
- **按上一台/下一台换台**：切换的是频道（组），而非同一频道内的线路；线路切换请用专门的线路入口
- **数据完全兼容**：底层仍以扁平频道列表存储，采集、检测、导出、回收站逻辑不变；升级安装不丢失任何频道与设置

## v1.9.0 更新（来源隔离 + 紧凑列表）

修复两个影响使用体验的问题：

- **来源互不影响**：重新采集网络采集源时，只更新本次采集源对应的频道，手动导入的「网络直播源」和「TVBox源」原样保留，不再被清空
- **检测范围隔离**：采集后的自动可用性检测只针对本次采集的频道，清理无效源时不会误删其他来源的频道
- **列表更紧凑**：频道卡片上下高度压缩约 30%，同屏可看到更多频道，信息完整不变

## v1.8.0 更新（分来源显示）

频道列表新增按来源分类切换显示：

- **三类来源**：网络采集源 / 网络直播源 / TVBox源，各自独立一组，顶部 chip 一键切换
- **多订阅后缀编号**：同一来源类型下有多个订阅（如导入了多个 TVBox 配置、多个直播源网址）时，以 ①②③ 后缀区分并分别显示，可单独筛选查看
- **联动筛选**：来源、分组、搜索三者叠加筛选；分组随所选来源自动更新；播放列表按当前筛选结果播放
- **来源标签**：每个频道卡片显示其来源（含后缀编号），一眼看清频道出处
- **兼容旧数据**：升级后老频道按来源文本自动归类，无需重新采集

## v1.7.0 更新（频道保留 / 删除 / 回收站）

频道列表的每个频道现在都能由用户决定是否保留、并自行删除：

- **单频道删除**：每个频道卡片右侧有删除按钮，长按菜单也有「删除此频道」，删除前二次确认
- **批量管理**：频道页「管理」进入勾选模式，支持全选 / 反选 / 删除所选 / 只保留所选
- **回收站**：删除的频道移入回收站，可单个恢复、全部恢复或清空；误删不怕丢
- **删除持久化**：用「名称+地址」唯一标识记录删除项，采集与各类导入都会自动过滤，删掉的频道不会被重新加回

## v1.6.0 更新（TVBox 导入彻底修复）

重新加回 TVBox 源导入，并彻底修复"导入后无法播放"的问题。经真实配置验证，根因是旧版把 `lives` 中的**订阅列表地址**当成单个频道直接播放。

- **正确展开订阅**：`lives[].url` 指向 txt/m3u 播放列表时，自动二次抓取并解析成真实频道（而非把订阅地址塞给播放器）
- **线路专属 UA**：继承每条线路的 `ua`（如 `okhttp/3.15`），播放与检测均使用该 UA，解决 403 问题
- **相对路径支持**：`./libs/tv/x.txt` 基于配置地址自动补全为绝对地址
- **注释兼容**：支持配置中常见的 `//` 行注释与 `/* */` 块注释
- **点播 API 隔离**：`sites` 字段是爬虫 API，不再误当直播频道
- **中文域名兼容**：自动将中文域名转 punycode
- 播放器与检测器改为按频道独立 UA 工作；TVBox 导出携带 UA 与台标

## 功能特性

### 采集中心
- 内置 20 个公开聚合源，参考以下项目整理：
  [iptv-org/iptv](https://github.com/iptv-org/iptv)、
  [HerbertHe/iptv-sources](https://github.com/HerbertHe/iptv-sources)、
  [Guovin/iptv-api](https://github.com/Guovin/iptv-api)、
  [fanmingming/live](https://github.com/fanmingming/live)、
  [peterhchina/iptv](https://peterhchina.github.io/iptv) 等
- 并发抓取 + 多镜像回退、频道名归一化、别名识别（CCTV/卫视）、去重合并
- 可用性检测：延迟、下载速度、响应特征三重判定
- 支持自定义订阅源（M3U / TXT / JSON），可单独启停

### 多格式导出
导出到用户选择的任意目录（Android SAF，含 SD 卡）：

| 格式 | 说明 |
|------|------|
| M3U / M3U8 | 标准播放列表，含 tvg-id / tvg-logo / group-title |
| TXT | 通用 `频道名,地址` 格式 |
| JSON | 结构化数据，含检测结果 |
| TVBox | TVBox 订阅配置（lives 携带 UA / 台标） |
| XSPF | XML 播放列表 |
| CSV | 表格数据，可用 Excel 打开 |

### 播放器
- 基于 **Media3 ExoPlayer**，支持 HLS / DASH / SmoothStreaming / RTSP / 渐进式流
- 频道列表抽屉、搜索、上一个/下一个
- 播放/暂停、拖动进度、倍速（0.5x–2.0x）、音轨/字幕选择、画面比例
- 手势：双击播放暂停、左右滑动进度、上下滑动音量/亮度、长按频道信息
- 画中画（PIP）、全屏、锁屏、后台唤醒策略
- 解码器偏好（自动/硬解/软解）、缓冲策略（标准/低延迟/大缓冲）
- 导入：M3U/M3U8/TXT/JSON 文件、网址、剪贴板；TVBox/影视仓配置（自动展开直播订阅）
